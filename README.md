

# 📚 Books & Blooms

Books & Blooms is an online bookstore where users can explore books, browse by categories, add books to their wishlist and cart, and place orders.

## ✨ Features

- User registration and login (including Google Login)
- Browse and search books by title, author, and category
- Shopping cart and wishlist
- Manage delivery addresses
- Secure online payments using Razorpay
- Admin dashboard for managing books, authors, categories, customers, and orders

## 🛠️ Technologies Used

**Frontend:** React, Vite, JavaScript, Tailwind CSS

**Backend:** Python, Django, Django REST Framework

**Database:** SQLite

**Authentication:** Token Authentication, Google OAuth

**Payment Gateway:** Razorpay
